# Tool Profiles

Tool profiles make the large command surface easier to use.

Built-in profiles:

- `minimal`
- `read_only_review`
- `safe_scene`
- `materials`
- `modeling`
- `animation`
- `full_standard`
- `developer`

Each profile defines enabled tool packs, permission profile, risky hidden tools, recommended skill packs, visible tool budget, and workflow hints.

Commands:

- `get_tool_profiles`
- `get_active_tool_profile`
- `preview_tool_profile`
- `set_active_tool_profile`
- `get_visible_tool_budget`
- `get_enabled_tool_packs`
- `set_enabled_tool_packs`
- `recommend_tool_profile`

Profiles that increase risk require confirmation. Reducing risk can be applied without expanding permissions.
