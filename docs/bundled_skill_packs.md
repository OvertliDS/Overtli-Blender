# Bundled Skill Packs

Bundled skill packs are metadata guides for common Blender workflows. They do not execute workflows automatically.

Phase 9B includes packs for reference modeling, hard-surface modeling, organic proportions, procedural modeling, Geometry Nodes patterns, PBR materials, texture baking, texture-painting preflight, sculpt refinement, cloth patterns, character rigging, animation blocking, product rendering, cinematic lighting, game asset export, scene cleanup, addon development, project repair, and diagnostics review.

Commands:

- `list_bundled_skill_packs`
- `get_bundled_skill_pack`
- `search_bundled_skill_packs`
- `recommend_skill_packs`
- `activate_skill_pack`
- `deactivate_skill_pack`
- `validate_skill_pack_readiness`

Readiness checks report missing tool packs, project setup blockers, approved-root gaps, and risk gates.
