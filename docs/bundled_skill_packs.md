# Bundled Skill Packs

Bundled skill packs are metadata guides for common Blender workflows. They do not execute workflows automatically.

Phase 9B includes packs for reference modeling, hard-surface modeling, organic proportions, procedural modeling, Geometry Nodes patterns, PBR materials, texture baking, texture-painting preflight, sculpt refinement, cloth patterns, character rigging, animation blocking, product rendering, cinematic lighting, game asset export, scene cleanup, addon development, project repair, and diagnostics review.

The browser/full-surface workflow layer also includes:

- `blender_scene_planning`: scene supervisor planning, tasks, todos, inspection, and evidence-backed completion.
- `spatial_snap_transform`: bounds, anchors, ground contact, snapping, cursor placement, scale/location/rotation, clearance, and object relationships.
- `scripted_blender_workflows`: when and how to use `execute_code`, `execute_blender_code`, registered context scripts, and Blender API docs after structured tools are insufficient.
- `workspace_project_safety`: project workspace resolution, temp workspace promotion, approved roots, project file reads/writes, and safe external-write planning.
- `cleanup_snapshot_recovery`: dry-run cleanup plans, snapshots, exact-scope deletion, rollback, cache cleanup, and post-cleanup verification.

Commands:

- `list_bundled_skill_packs`
- `get_bundled_skill_pack`
- `search_bundled_skill_packs`
- `recommend_skill_packs`
- `activate_skill_pack`
- `deactivate_skill_pack`
- `validate_skill_pack_readiness`

Readiness checks report missing tool packs, project setup blockers, approved-root gaps, and risk gates.
