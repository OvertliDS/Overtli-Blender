# Tool Packs

Tool packs group the large Overtli-Blender command surface into discoverable
sets without hiding the underlying atomic tools.

Current packs:

- `core`: status, permissions, approvals, operation runtime, and discovery.
- `scene_intelligence`: scene inspection, verification, screenshots, and health.
- `verified_editing`: structured edits, selection, deformation, cleanup, and rollback.
- `materials`: material, shader, texture, preview, and future baking workflows.
- `geometry_nodes`: Geometry Nodes inspection, templates, modifiers, and procedural workflows.
- `animation_presentation`: animation, rigging, cameras, lighting, rendering, and compositor workflows.
- `advanced_animation`: Phase 9A animation system inspection, keyframes, F-Curves, and workflow batches.
- `action_library`: action listing, inspection, creation, assignment, duplication, rename, and deletion.
- `nla_workflows`: NLA track/strip creation, editing, muting, deletion, and validation.
- `drivers`: allowlisted driver DSL validation, driver creation, driver inspection, and driver removal.
- `rigging`: rig templates, control metadata, IK chains, rig constraints, custom rig properties, and validation.
- `pose_library`: pose snapshots, pose application, pose comparison, manifest-backed pose assets, and deletion.
- `shot_workflows`: shot ranges, camera cuts, timeline markers, shot plans, and validation.
- `simulation_workflows`: simulation capability detection, stack inspection, rigid body/cloth/soft body/hair intent, cache status, preview, bake, and clear plans.
- `motion_validation`: aggregate motion validation and motion path preview planning.
- `asset_workflows`: local assets, import/export, dependencies, and scene kits.
- `addon_knowledge`: addon management, API knowledge, snippets, skill packs, and review packages.
- `release_diagnostics`: release, diagnostics, logs, and packaging support.

Use `discover_tool_packs`, `get_tool_pack`, `search_tools`, and `get_tool_spec`
to inspect the current runtime surface. Search is keyword-based in Phase 7B.
